# Next milestones after this alpha

1. Obtain documented permission for commercial MusicBrainz API identity resolution, or license/build an appropriate legally sourced recording ID lookup index.
2. Evaluate coverage over representative actual underground techno/vinyl release metadata; account for missing MBIDs.
3. Benchmark browser DSP against a permissively licensed second engine on real authorized recordings; calibrate confidence and octave errors.
4. Improve metadata matching with ISRC, catalog number, release version, length and track artists; no false automatic assignment.
5. Separate user-owned BPM corrections from expiring Discogs collection metadata while preserving source rules.
6. Upgrade job queue to durable server-side process for legally accessible metadata; browser-local audio cannot outlive file permissions.
7. Evaluate performance at 100/500/1000 releases, plus printer geometry and PDF output.
8. Obtain explicit commercial redistribution/printing rights from providers before paid plans.
9. Re-review privacy, security, concurrency, provider costs and rate limiting.
