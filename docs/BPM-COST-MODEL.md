# Current BPM operating model

Local tempo analysis uses the user's browser CPU and memory. It uploads no audio,
requires no external BPM subscription/key and creates no per-track catalog API cost.
Discogs metadata/OAuth operations retain their existing policies and limits.
The archive availability probe is isolated research, not a required inference service.

The prior external catalog integration has been removed. Historical cost estimates
are available in Git history; do not provision a provider as part of this change.
No new pricing, billing integration or production infrastructure was introduced.
